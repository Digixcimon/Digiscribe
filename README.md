# 📧 Direct Gmail Contact Form

A secure, modern contact form that sends emails directly to your Gmail account without any third-party services. Built with Flask and featuring a beautiful, responsive design.

## ✨ Features

- **🔒 Secure**: Direct Gmail SMTP integration with App Passwords
- **🎨 Modern UI**: Beautiful, responsive contact form design
- **⚡ Fast**: Minimal dependencies, quick setup
- **📱 Mobile-friendly**: Works perfectly on all devices
- **✅ Validation**: Both client-side and server-side validation
- **🚫 No Third-parties**: No external services or dependencies

## 🚀 Quick Setup

1. **Clone or download** this project
2. **Run the setup script**: `./run.sh`
3. **Configure Gmail credentials** in the `.env` file
4. **Start using** your contact form!

- `contact-form.html` - Beautiful, modern contact form
